Antenna Array Theory & Mathematics

An antenna array is a set of radiating elements positioned along a spatial geometry to produce a directional radiation pattern via electromagnetic wave interference.

1. Far-Field Array Factor (AF)

For two isotropic point sources separated by distance d along the X-axis with excitations A₁∠α₁ and A₂∠α₂, the far-field pattern at azimuth angle φ is given by:

AF(φ) = A₁ e^(j (α₁ + ψ)) + A₂ e^(j (α₂ - ψ))
where ψ = (k · d / 2) · cos(φ) and k = 2π / λ

2. Array Radiation Power Pattern & Interference

The far-field power is proportional to |AF(φ)|² = |E(φ)|²:

|AF(φ)|² = A₁² + A₂² + 2 A₁ A₂ cos(k · d · cos(φ) - Δφ)
where Δφ = α₂ - α₁

Constructive vs Destructive Interference:

  • Incoherent Baseline (P₀ = A₁² + A₂²): Power radiated without mutual phase coherence.
  • Constructive Interference (|AF|² > P₀): When cos(...) > 0, wave crests reinforce, amplifying power up to (A₁ + A₂)².
  • Destructive Interference (|AF|² < P₀): When cos(...) < 0, opposing phase wavefronts cancel, pulling power below P₀ down to (A₁ - A₂)² (deep nulls).

3. Broadside vs Endfire Arrays

  • Broadside Array (Δφ = 0°): Maxima occur perpendicular to the array line (φ = 90° and 270°).
  • Endfire Array (Δφ = ±kd): Maxima occur along the array axis (φ = 0° [Front +X] or 180° [Back -X]).
  • Grating Lobes: When element separation d ≥ λ, additional identical maxima (grating lobes) emerge in visible space.

4. Electronic Beam Steering

To steer the main lobe to a desired target angle θ₀, the progressive phase shift must satisfy:

Δφ = -k · d · cos(θ₀)
